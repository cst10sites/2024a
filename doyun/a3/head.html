Common CSS Tags

Tag Definition Example
body Selects the entire document's body. body { background-color: #f0f0f0; }
p Selects all <p> (paragraph) elements. p { font-size: 16px; color: #333; }
h1, h2, ... Selects heading elements (e.g., <h1>, <h2>, etc.). h1 { font-weight: bold; }
#id Selects an element with a specific ID attribute. #header { background-color: #333; color: #fff; }
.class Selects elements with a specific class attribute. .button { background-color: #007bff; }
a Selects all anchor (link) elements. a { text-decoration: none; color: #007bff; }
ul Selects unordered lists. ul { list-style-type: disc; }
ol Selects ordered lists. ol { list-style-type: decimal; }
li Selects list items. li { padding: 5px; }
div Selects <div> elements, commonly used for layout. div.container { width: 80%; margin: 0 auto; }
