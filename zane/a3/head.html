Commonly used tags outside the <body>

Tags outside the body Definition Examples
<!DOCTYPE html> Tells the browser it's HTML
<html lang="en"> The language of the website This page is english
<meta charset="UTF-8"> Metadata of a HTML document.
<title></title> Adds a title to the website's tab in the browser. The Title
<style></style> Makes the website cooler Background the look of this website
<link rel="stylesheet" href="link"> Code that defines the looks of your webpage. The homepage and this page point to a common style.css file that controls the look of these pages.
<link rel="icon" type="image/x-icon" href="favicon.ico"> Creates an image next to the title in the browser's tab. This websites logo
