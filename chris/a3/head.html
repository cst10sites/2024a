Common HTML Tags

Tag Definition Example
<DOCTYPE html> Defines HTML5 Document No Examples
<html lang="en"> Specifies Language for the HTML Document This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English.
<meta charset="UTF-8"> Specifies character encoding for the HTML document No Examples
<title></title> Changes the title that shows for the tab of website
<style> Section that describes the internal CSS of the page Show <style>...</style> that makes the background black
<link> Tag that points to an external CSS file The homepage and this page point to a common style.css file that controls the look of these pages
<link> Tag that adds a favicon(Picture to the left of the Title)
