Tag Definition Examples
<!DOCTYPE html> This tag tells the web browser what document type to expect. No examples*.
<html lang="en"> This tag indicates to the webpage which languge it will be in. This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English.
<meta charset="UTF-8"> This code indicates the web page's character encoding. No examples*.
<title>
</title> 		You use the title tag to put a title for your webpage which sits up top. Tile is underlined in blue.
<style>
</style> 		Section that describes the internal CSS of the page. <style> body
{
background-color:black;
}
</style>
<link rel="stylesheet" href=""> Tag that points to an external CSS file. The homepage and this page point to a common style.css file that controls the look of these pages.
<link rel="icon" type="image/x-icon" href=""> Tag that adds a favicon. Circled in yellow.
