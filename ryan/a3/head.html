Commonly used tags outside the <body>

List of tags that are outside of the body. Definition Example
<!DOCTYPE html> This tag tells the browser the html version that the website it's coded in.
<title></title> This tag adds a title to the tab of your web browser. Top of the broswer.
<style></style> This tag changes the graphical interface of the website.
<html lang="en"> This tag tells the browser the language that its in.
<link rel="icon" type="image/x-icon" href="favicon.ico"> This tag will make an icon on the tab of your web broswer. The small icon on your browsers tab.
<meta charset="utf-8"> This tag will define the metadata within the tab.
<link rel="stylesheet" href="link"> This is external CSS that changes the look of the webpage.
