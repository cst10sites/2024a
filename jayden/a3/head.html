Click here to see Common HTML Tags inside <body>.



Tag Definition Examples
<!DOCTYPE html> The doctype is something that defines that this document is an HTML5 document.
<html lang="en"> This tells what language the website is. This page is set to "en" which means English. This tells websites like google translate that your default language is English.
<meta charset="UTF-8"> This tells you the character encoding for the HTML document.
<title></title> This tag creates a title for your website. You see the title on the top of your tab.
<style></style> This tag describes the internal CSS of this page. <style>
body {
background-color: black;
color: white;
margin: 25px 125px;
font-family: Arial;
}

h1, h2 {
color: yellow;
}

a.btn:hover {
background-color: darkcyan;
box-shadow: 5px 10px black;
}
</style>
<link rel="stylesheet" href="styles.css"> This tag will use the CSS from your CSS file. The homepage and all the pages with this tag will point to a common CSS file that controls how the page looks.
<link rel="icon" type="image/x-icon" href="/images/favicon.ico"> This lets you add an icon next to your browser title.
