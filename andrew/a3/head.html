Commonly used tags outside the <body>

Tags outside the body Definition Examples
<!DOCTYPE html> Tells the browser what version of HTML the document is written in.
<html lang="en"> Tells the browser what language the website is written in (Useful for translations). This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English.
<meta charset="UTF-8"> Defines the metadata of a HTML document.
<title></title> Adds a title to the website's tab in the browser.
<style></style> Defines the looks of your webpage inside the document. <style> background-color: white; </style>
<link rel="stylesheet" href="link"> links to external CSS code that defines the looks of your webpage. The homepage and this page point to a common style.css file that controls the look of these pages.
<link rel="icon" type="image/x-icon" href="favicon.ico"> Creates an image next to the title in the browser's tab.
