Images

There are 3 types of images that all web browers can open: .jpg/jpeg, .png, .gif

Photographs are often saved as .jpg because they are highly compressible (small file size). Graphics use .png because this format supports transparent backgrounds. Animated images are usually .gif, but are highly compressed.
