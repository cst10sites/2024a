Commonly used tags outside the <body>

Tags outside the body Definition Examples
<!DOCTYPE html> Lets the browser know what file type the document is.
<html lang="en"> Defines the language of the document This site is programmed in English (<html lang="en">), therefore other users browsing from a different country, will get a prompt from their browser to automatically translate the site.
<meta charset="UTF-8"> Defines the metadata of an HTML document.
<title></title> Defines the text written whithin the tab of the browser
<style></style> Defines an internal CSS section within an HTML document <style>
color: red;
font-family: helvetica;
</style>
<link rel="stylesheet" href="link"> Links an external CSS document to the HTML file. CSS controls the visual parts of your website. Having an external CSS document is handy in cases like this where both index.html and head.html use the same external CSS file (styles.css) as they are common in terms of style
<link rel="icon" type="image/x-icon" href="favicon.ico"> Creates an image next to the title in the browser's tab.
