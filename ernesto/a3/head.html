Common HTML tags

Tag Definition Examples
<!DOCTYPE html> It helps the webpage to render in the intended form. There's no examples.
<html lang="en"> A tag used to specify the language of the elements content. This page is set to “en” for English. This tag helps websites such as Google Translate know the default language for this page is English.
<meta charset="UTF-8" > Html tag used to indicate the page's character encoding. There's no examples.
<Style> </style > Section that describes the internal CSS of the page. Show <style >...</style > that makes the background black.
<title> </title > Tag that is used to show what the name of the web page is.
<Link > This tag can be used to place "favicons".
<Link> Tag that points to an external Css file. The homepage and this page point to a common style.css file that controls the look of these pages.
