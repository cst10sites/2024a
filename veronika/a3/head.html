HTML/CSS Guide

Common HTML tags outside <body>

Tag Definition Examples
<!DOCTYPE html> The declaration is not an HTML tag. It is an "information" to the browser about what document type to expect. <!DOCTYPE html>
<html lang="en"> A tag that specifies what languange the website is written in. <html lang="en">
<meta charset="UTF-8"> The meta tag specifies which character set a website is written with. <meta charset="UTF-8">
<title></title> The title of the tab
<style> Inside <head>, internal CSS means the CSS is included on the page, wrapped in style tags. <style> #wrapper { width:960px; margin:0 auto; } </style>
<link rel="stylesheet" href="your-file-here.css"> Inside <head>, external CSS refers to a file location. <a target="_blank" href="https://www.w3schools.com/html/default.asp">
<Link rel="icon" type="image/x-icon" href=""> Favicon is the image beside the title on the browser tab. Code is inside <head>, above <style>.
