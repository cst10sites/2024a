External CSS

Internal and inline CSS codes go inside the HTML file but external CSS is inside a separate file referenced by the link tag within head. One benefit for using external CSS is allowing multiple webpages to share the same CSS theme by referencing to the same CSS file. Making changes to this CSS file makes changes to all the pages' theme.
