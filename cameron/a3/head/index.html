Common HTML tags outside the body

Tag Definition Examples
<DOCTYPE html> Specifies what coding language your document is to the web browser. This document is set to html because it is an html document.
<html lang="language"> </html> The html tag is a container for all your html code except for the <DOCTYPE html> tag. The lang attribute in the html tag specifies the language of the webpage for the web browsers so they only make it shows up to people searching on the web browser in the same language. This page is set to en which stands for english so it should only show up if you search in english.
<meta charset="UTF-8"> The meta tag defines the data about your data. The charset attribute is short for character set. UTF-8 is a character set that contains almost all of the charcters and symbols in the world. Here is a link if you want to learn more about the UTF-8 character set.
<title>WriteTitleHere</title> The title tag changes the title at the top of the tab.
<style>WriteCSSHere</style> The style tag allows you to use internal CSS in your code. Just write the CSS in between your style tags! The example would make the background black. <style>

background-color: black;

</style>
<link rel="stylesheet" href="documentName.css"> The link tag allows you to link other documents to your webpage. The rel attribute is required and explains the relation between the document you are linking to your webpage. The href attribute attaches the actual document. The homepage and this page point to a common style.css file that controls the look of these pages. If you hit CRTL+U you should be able to see my code on line 9
<link rel="icon" type="image/x-icon" href="faviconlink.ico"> The link tag, rel attribute, and href attribute serve the same purpose as before but now they are being used to show a favicon. The type attribute specifies the internet media type of the link.
